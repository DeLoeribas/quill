Quill

A minimal, fast personal RSS reader you run yourself.

Self-Hosted

Deploy it on your own site

Quill is open source and built to run on plain PHP hosting — no server you don't already control. Clone it, drop in a config file, and package a clean copy for upload:

# clone and configure
git clone https://github.com/DeLoeribas/quill.git
cd quill
cp src/config.sample.php src/config.php

# build a clean upload with no personal data
bin/package-for-deploy.sh

Upload the contents of ./deploy/, pointing your document root at public/. Add a cron job (or a URL-based one for hosts without shell access) to keep feeds refreshing in the background. Full deployment guide on GitHub →

What Is Quill?

A place to read your feeds without an account, a subscription, or someone else's server deciding what you see. Add any RSS, Atom, or JSON feed by URL — paste a site's link and Quill finds the feed for you, or paste a YouTube channel and it resolves straight to that channel's video feed.

Plain PHP, Not a Platform

No framework, no database, no build step. Quill stores everything as flat JSON files and runs on whatever PHP hosting you already have — from a few dollars a month of shared hosting to your own Mac.

Built for Speed

Refreshing dozens of feeds fetches them concurrently instead of one at a time, the frontend is vanilla JS with no framework to ship, and there's no database to query — pages load and refresh fast, even with thousands of stored items.

Yours, Not Rented

One login gates the whole thing. Your feeds, your read history, your saved articles — all in files you control, exportable to OPML any time you want to leave.
View on GitHub

Features

Everything you need, nothing you don't

⚡

Built for Speed

Feeds refresh concurrently via curl_multi instead of one at a time, and with no framework or database in the way, the UI stays snappy at any size.

➕

Add Feeds Instantly

RSS 2.0, Atom, and JSON Feed all supported. Paste a plain site URL and Quill auto-discovers any feed(s) it declares.

📁

Folders & Unread

A collapsible folder tree groups your feeds, plus a dedicated Unread view across every feed at once.

⏸️

Enable / Disable Feeds

Pause a feed without losing its history — it keeps its items but is skipped by every refresh until resumed.

✓

Read / Unread Tracking

Unread counts everywhere they matter, with a one-key toggle to mark any item read or unread.

🔖

Save Items

Keep the articles worth returning to in a dedicated Saved view, independent of read state.

🔄

Manual & Scheduled Refresh

Refresh on demand from the header, or let cron keep everything current in the background.

⏱️

Per-Feed Refresh Interval

Feeds that declare their own cadence use it automatically; every other feed gets a clickable preset from 15 minutes to 24 hours.

🔔

Live Unread Badges

The open tab quietly polls for new items and updates sidebar counts — without ever touching what you're currently reading.

📤

OPML Import & Export

Bring your feeds from anywhere, and take them with you again whenever you like.

🔒

Single-User Login

A username, a password, a bcrypt hash — no database, no third-party auth, gating every page and request.

🖼️

Favicons & Thumbnails

Each feed shows its real favicon, and items show a preview image when one can be found — no third-party image service involved.

🔎

Per-Feed Content Filters

Skip items matching a comma-separated list of strings, set individually per feed.

📺

YouTube Channels

Paste a channel, handle, or legacy custom URL and Quill resolves it to that channel's video feed automatically.

🔍

Saved Searches

Pin any search query as a named view in the sidebar, alongside your folders, for instant recall later.

⌨️

Keyboard-Driven

Navigate entirely without a mouse — j/k or arrow keys move through feeds and items, and ? opens the full shortcut list.

↔️

Resizable Layout

Drag the sidebar and reading pane to whatever width suits you — remembered across reloads.

💾

Backup & Restore

Download every feed, folder, filter, saved search, and read/starred state as one file, and restore it later or on a fresh install.

📱

Mobile Ready

Below tablet width the sidebar becomes a slide-in drawer with touch-friendly controls throughout.

🌗

Automatic Dark Mode

Follows your system appearance, with contrast tuned for both light and dark.
